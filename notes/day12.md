## B. 幻覺偏差統計

### OBSERVE 路徑（tick_aware=False）的偏差

```
樣本數 : 15 條
ratio = net_real / net_star

  中位數 : -0.0051  （net_star 的 0.5%，即 99.5% 都是幻覺）
  平均數 : -0.0533
  標準差 : 0.0833

  net_real 最大值 : -$10（連 0 都沒到過）
  正 EV 條數      : 0
```

### tick_aware=True 候選的偏差（第二階段 Quoter 驗證）

```
樣本數 : 31 條（全部候選）
ratio = net_real / net_star

  中位數 : -0.0277  （net_star 的 2.8%，即 97.2% 是幻覺）
  正 EV 條數 : 0

  最接近正 EV：
    USDT→USDC→DAI  net_star=$1570  net_real=-$5.26  差 $10.76
    USDT→USDC→DAI  net_star=$1550  net_real=-$6.57
```

### 校正公式（結論）

```
# OBSERVE（tick_aware=False）
net_real ≈ net_star × (-0.005)   # 幾乎完全無效，不可用

# tick_aware=True 候選
net_real ≈ net_star × (-0.028)   # 仍是負值，校正公式無意義
```

**校正公式的根本問題：** ratio 的標準差（0.083）遠大於中位數（-0.028），
意味著偏差來源不是一個固定的乘數，而是每條路徑的 v3 池情況各異。
→ **沒有通用的校正公式，Quoter 是唯一可信驗證方式。**

## 今天的核心發現

**在這兩天的掃描窗口內，沒有真實的三角套利機會。**

這有幾種可能的解釋：
1. 機會存在，但持續時間 < 1 block（12 秒），掃描器太慢
2. 機會存在，但被競爭者在同一 block 內搶走
3. 當前市場狀態（volatility 低）機會本來就少
4. 掃描器的 pool 覆蓋率不足（漏了某些路徑）

## 最接近正 EV 的路徑分析

```
USDT→USDC→DAI  net_star=$1570  net_real=-$5.26  gas=$5.50
                                差距 = -$5.26 - $5.50 = -$10.76
```

這條路徑：
- amm_out 算出 $1570 的假套利空間
- Quoter 真實值是 -$5.26（略微負值）
- 距離正 EV 門檻（$5.50）只差 $10.76

**這是目前最接近真實機會的路徑。** 如果池子在某個時刻比現在稍微不平衡一點，
可能就會出現真實的正 EV 機會。這正是為什麼要長期掃描。
