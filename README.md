## 硬規則（永遠不要自動執行）
- 任何真實資金的鏈上交易 —— 必須我逐筆確認才發送
- 任何 token approve —— 必須明確額度，永不 unlimited
- 把私鑰或助記詞寫進任何檔案、log、對話或截圖
- 把 .env 加進 git
- 註冊需要 KYC 的服務、綁定支付方式
- 用真實資金測試「先試試看」的想法

## 需要先問我的
- 花任何錢（伺服器、API 方案、訂閱）
- 安裝需要 sudo 的東西
- 對外發佈任何內容（含共學打卡）

## 專案脈絡
21 天鏈上套利共學，2026-08-05 至 08-26。
我的底子：寫過合約、碰過 Web3，沒做過套利。每天 2-3 小時。
目標：建立成本模型、做出一個 scanner、完成一筆小額真實交易、培養鏈上資料能力。
核心原則：速度的戰場已關閉，我要贏的是覆蓋度、建模、資訊三種比賽。
